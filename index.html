About

What is this

Cat Command Chat is a small private chat room for a few people. Everyone who opens this page lands in the same room and sees the same messages.

It started as a two person chat built by a friend. Its look lives on as the Orbit skin.

How it works

Messages are saved to a database and show up for everyone instantly. The dot at the top shows who else has the page open, and you can see when someone is typing.

There is no sign up. The first time you open the page, it quietly makes a guest account for this browser. No email, no password, and nothing linked to other services unless the Your account section says so.

That guest account lives in this browser. Clearing site data, private browsing, or switching browsers or phones makes you a new person in the chat. Set a name so others know it's you.

Tap the paperclip to share a file up to 50 MB. Pictures show in the chat, other files download with a tap. Only people in this chat can open them. Web addresses you type become tappable links.

Tap any message to react with an emoji. Tap a reaction to add or remove yours. Pick a ding or a meow in Sound to hear new messages.

The last 500 messages are shown.
