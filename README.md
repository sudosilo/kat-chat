Cat Command Chat

Cat Command Chat is a private group chat for a small circle of invited people.

Members chat with names and colors, send text, files, voice notes, and GIFs, and react, reply, edit, and mention. A Claude member can answer in the chat. Chess can be played inside the chat. The menu offers day, night, and other themes, sounds, notification choices, and an About page. It installs to the home screen and has Android and Windows app builds.

Live at kat-chat-flame.vercel.app
